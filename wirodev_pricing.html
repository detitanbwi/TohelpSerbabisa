1. ALUR KERJA & FASE PENGEMBANGAN SISTEM (SEKUANSIAL)
FASE 1 (Mayor): Fondasi Multi-Cabang & Hirarki Role
  1. Pembangunan Modul Cabang Unlimited: Menyiapkan struktur tabel database dan form cabang untuk mendukung penambahan cabang tanpa batasan kuota.
  2. Hirarki Admin (Owner) ke Manager Cabang: Mengunci wewenang agar hanya Owner yang dapat membuat akun dan menugaskan Manager Cabang.
  3. Registrasi Karyawan oleh Manager Cabang: Manager Cabang memiliki form khusus untuk mendaftarkan Helpman / Joki baru yang otomatis terikat ke cabangnya.
  4. Dukungan Karyawan Unlimited: Setiap cabang bebas menampung helpman dalam jumlah tak terbatas.
FASE 2: Manajemen Visibilitas Helpman / Joki
  1. Penyediaan Switch Toggle Visibilitas: Menambahkan kontrol aktif/nonaktif (Tampilkan / Sembunyikan) pada daftar helpman di panel cabang.
  2. Logika Filter Penugasan: Helpman berstatus "Sembunyikan" otomatis terisolasi dari penugasan order dan tidak muncul di aplikasi customer.
  3. Reaktivasi Cepat: Manager dapat mengaktifkan kembali helpman kapan saja saat mitra siap bertugas kembali di lapangan.
FASE 3 & 4: Logika Transaksi (Free Jemput + Tipping) & Integrasi Flutter
FASE 3: Kuota Free Jemput & Auto Tipping
  1. Pengaturan Kuota Jarak Free Jemput: Admin/Manager mengatur batas kilometer jemput gratis (misal 0-2 KM). Biaya per KM hanya dihitung pada sisa jaraknya.
  2. Input Tipping per Order: Form pesanan mendukung input nominal tip secara fleksibel.
  3. Auto Include ke Transaksi: Nominal tip otomatis terakumulasi ke Grand Total dan masuk ke rincian komisi helpman.
FASE 4: RESTful API & Mobile Client (Flutter)
  1. RESTful API Sync: Menyediakan endpoint API untuk data cabang, list helpman aktif (visible only), free jemput, dan tipping.
  2. Pembaruan Flutter Mobile App: Integrasi UI mobile Android untuk input tipping, rincian biaya transparan, dan filter mitra aktif.
2. CAKUPAN PEMBARUAN TAMPILAN (UI) & LOGIKA PROSES
2.1 Pembaruan Tampilan Antarmuka (UI)
  • Form Cabang Unlimited: Input nama cabang, alamat, penanggung jawab, dan wilayah operasional tanpa batasan limit.
  • Form Registrasi Manager Cabang (Panel Owner): Akses khusus Owner untuk membuat akun Manager Cabang baru.
  • Form Registrasi Helpman / Joki (Panel Manager): Form penambahan helpman baru di bawah cabang yang dikelola.
  • Toggle Switch Visibilitas Helpman: Tombol status "Tampilkan / Sembunyikan" pada tabel daftar karyawan.
  • Form Konfigurasi Kuota Free Jemput: Input angka batas kilometer bebas biaya jemput per cabang.
  • Field Input Tipping pada Form Transaksi: Input nominal tip per order yang mengupdate kalkulasi total secara live.
  • UI Mobile Flutter Client: Penyesuaian antarmuka mobile untuk pilihan tipping dan tracking helpman yang aktif.
2.2 Pembaruan Proses & Logika Bisnis
  • Struktur Relasi Multi-Tenant Cabang: Data karyawan dan order terisolasi dan terikat pada foreign key `cabang_id`.
  • Role & Permission Strict: Owner dapat membuat Manager Cabang; Manager Cabang hanya mengelola Helpman cabangnya.
  • Filtering Helpman Aktif: Query pencarian mitra order memfilter kondisi `is_visible = true`.
  • Formula Kuota Jarak Free Jemput: Jarak Dihitung = MAX(0, Total Jarak - Kuota Free).
  • Formula Akumulasi Tipping: Total = Tarif Dasar + (Jarak Dihitung x Tarif/KM) + Tipping - Diskon.
  • RESTful API Sanctum: Endpoint aman untuk sinkronisasi data transaksi dan mobile client Flutter.

3.3 FASE 3: Kuota Jarak Free Jemput & Input Tipping Transaksi
Definition of Done (DOD)
  • Sistem memotong kuota free jemput dari total jarak sebelum dikalikan tarif per KM.
  • Input nominal tipping bebas dan otomatis terakumulasi ke Grand Total transaksi.
  • Rincian tipping tercatat pada struk dan detail komisi helpman.
Langkah Pengujian (Testing Steps)
Setting: Kuota Free Jemput = 2 KM, Tarif Dasar = Rp 10.000, Tarif/KM = Rp 3.000.
  1. Buat transaksi dengan total jarak 5 KM (Jarak kena biaya = 5 - 2 = 3 KM -> Rp 9.000).
  2. Input nominal Tipping = Rp 5.000.
  3. Verifikasi Grand Total: Rp 10.000 + Rp 9.000 + Rp 5.000 = Rp 24.000 (Tepat).
